
# AI-Powered Healthcare Operations Analytics

## Project Overview
An end-to-end healthcare data analytics
project focused on understanding patient
appointment attendance and predicting
appointment no-shows.

## Business Problem
Hospitals experience operational challenges
when patients miss scheduled appointments.

This project aims to identify no-show
patterns and develop data-driven
recommendations to improve appointment
utilization.

## Technology Stack
- MySQL
- Power BI
- Python
- Pandas
- Scikit-learn
- Machine Learning

## Key Performance Indicators
- Total Appointments
- No-show Rate
- Attendance Rate
- Average Waiting Days
- Model Recall
- Model Precision

## Project Status
Currently in development.

## Dataset
Medical Appointment No Shows dataset
Source: Kaggle
